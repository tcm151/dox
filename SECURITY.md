# Security Policy

## Supported Versions

Only the latest stable release is supported for security fixes. The current release is `2026.6.0`; older releases may not receive fixes, so update before reporting an issue.

## Reporting a Vulnerability

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/tcm151/dox/security/advisories/new). If that feature is unavailable, contact the maintainer using the email address listed on the [GitHub profile](https://github.com/tcm151). Do not report suspected vulnerabilities in public issues or discussions.

Include the affected version or commit, deployment mode, security impact, and concise reproduction steps. A minimal proof of concept is useful when it does not expose real user data. Do not access, modify, or disclose other users' data, or disrupt services while investigating.

There is no bug bounty program.

## Response and Disclosure

The project is maintained by a solo maintainer, so response times are best-effort. We aim to acknowledge reports within 7 calendar days, provide an initial assessment within 14 days, and send status updates at least every 30 days.

We aim to coordinate remediation and public disclosure within 90 calendar days of a report. Please avoid public disclosure before a fix is available or 90 days have passed. If remediation needs more time, we will discuss an updated timeline with the reporter.
